# KeepFit
SNUSV Ideathon

GLP-1(위고비·마운자로) 감량 치료를 마친 환자의 **체중 유지 프로그램** — 환자용 웹앱(PWA) 데모.

병원이 치료 종료 시점에 환자를 초대하고(B2B2C), 환자는 매일 AI 코치 전화만 받으면 체중·식욕·수면이 기록됩니다. 위험 신호가 보이면 원장님이 내원을 요청합니다.

## 요금 (서비스 이용료만, 약값·진료비는 병원에 별도 지불)

**환자 → KeepFit** (앱 결제, 첫 2주 무료, 단약 단계에 맞춰 요금이 내려감)

| 기간 | 통화 | 월 요금 |
| --- | --- | --- |
| 1–3개월 · 집중기 | 매일 | 4.9만원 |
| 4–6개월 · 적응기 | 주 2–3회 | 2.9만원 |
| 7개월~ · 혼자서 유지 | 주 1회 | 1.9만원 |

6개월 이용 시 1인당 약 23.4만원 · 목표 범위(±2kg)를 지키면 마지막 달 요금 환급 · 회사 복지포인트 결제 가능

**의원 → KeepFit**: 환자 모니터링·후속 관리 도구 월 14만 9천원 (12개월 → 1곳당 연 178.8만원)

가격과 이용 기간은 실제 결제·유지 데이터로 검증할 가정이에요. 시장 규모와 근거는 [시장 분석](docs/market-analysis.html)을 보세요.

## 데모 시나리오

**발표용 (두 화면 연동)**: 왼쪽에 병원 대시보드, 오른쪽에 환자 앱(휴대폰 크기)을 띄워요.

1. 환자 앱 홈 맨 아래 **데모 → 위험 신호 시나리오로**, 이어서 **지금 받기**로 AI 통화
2. 통화가 끝나면 대시보드에서 이지은이 **위험**으로 올라옴
3. 대시보드에서 **내원 요청 보내기** → 시간 2–3개 선택 → 보내기
4. 환자 앱 홈 배너 → 알림 화면에서 원장님이 고른 시간 중 하나로 **예약**
5. 대시보드에 **내원 예약 확정**, 메모를 보내면 환자 앱 홈 맨 위에 "새 메모" → 환자가 **확인했어요**를 누르면 대시보드에 "환자가 읽음"
6. 끝나면 환자 앱 **처음부터** 또는 대시보드 설정 → **데모 초기화**

**환자 앱만**: 홈 맨 아래 데모 버튼으로 정상/위험을 바꿔요. "처음부터"를 누르면 온보딩부터 다시 시작해요.

## AI 코치 체크인 (전화 · 소리 없이 누르기)

환자는 **알림을 받고, 말하거나 눌러서 답하기만** 하면 돼요. 앱을 열어 기록할 필요가 없어요.

- `#/os` — 데모용 휴대폰 바탕화면. 저녁 9시 체크인 알림이 내려오고 **전화로 답하기 / 소리 없이 답하기**를 고를 수 있어요. 대시보드 이지은 카드의 **지금 전화 걸기**를 누르면 바로 알림·전화가 와요
- 통화 중 AI가 체중 → 식욕 → 수면 → 근력 운동 → 원장님께 전할 말을 물어요. 크롬 음성 인식으로 "칠십이 점 육", "한 8쯤?", "하루 종일 배고팠어요", "다섯 시간 반"처럼 대충 말해도 알아듣고, 한 번에 여러 개를 말하면 남은 질문은 건너뛰어요
- 말 대신 **화면에서 답할 수도** 있어요. 질문마다 입력 방식이 달라요: 체중은 후보 + 숫자 입력(±0.1kg), 식욕은 1–10 버튼, 수면은 태그 + 직접 입력, 운동은 두 버튼, 전할 말은 여러 개 고르는 태그
- 통화 중 **소리 없이 눌러서 답하기**를 누르면 AI 음성·마이크를 끄고 화면으로만 진행해요 (지하철·회의 중). 전화가 울릴 때도 바로 고를 수 있어요
- 용량·처방 질문(말 또는 "약 관련 질문 있어요" 태그)에는 답하지 않고 "원장님께 전달"로 기록해요
- 체크인 결과는 통화 요약, 앱 홈의 내 상태, 리포트 주간 그래프, 원장님 대시보드(환자 카드·AI 통화 표·통화 원문)에 바로 반영돼요. 눌러서 답한 경우 "버튼 응답"으로 표시돼요

구조: `src/voice/script.ts`(질문·답 해석·안전 규칙) · `src/voice/speech.ts`(브라우저 말하기·듣기) · `src/voice/result.ts`(결과 → 대시보드 기록) · `src/components/AnswerPanel.tsx`(질문별 입력 패널) · `src/screens/PhoneHome.tsx`(바탕화면·알림). 실제 전화(Vapi·Twilio 등)로 옮길 때는 `speech.ts`만 바꾸면 돼요. 음성 인식은 크롬에서 동작하고 처음 받을 때 마이크 권한을 물어봐요. 지금 기록은 같은 브라우저 안에만 저장돼요.
