# 유지케어 병원 대시보드 (원장님용)

환자 앱(레포 루트)과 짝을 이루는 **병원용 웹 화면** 목업이에요. 빌드 없이 `index.html`을 브라우저로 열면 바로 동작해요.

## 화면

| 메뉴 | 하는 일 |
| --- | --- |
| 환자 | 어젯밤 AI 통화 기준으로 확인할 환자를 위로 올려 보여줘요. 환자를 누르면 체중·식욕·수면, 통화 한 줄, **내원 요청**(진료 가능 시간을 골라 함께 보냄)과 **메모 보내기**(태그만 눌러서 보냄) |
| AI 통화 | 어젯밤 통화 목록과 AI 요약, 통화 원문 |
| 내원 일정 | 이번 주 예약, 내원 요청으로 잡힌 예약, 제안 중인 시간, 빈 시간 |
| 환자 초대 | 진료실 QR, 초대 링크·문자, 초대 현황 |
| 병원 성과 | 참여 수, 유지율, 재방문율 (예시 데이터) |
| 설정 | AI 전화 시간, 알림 기준, 제안할 진료 시간, 메모 태그 |

## 환자 앱과 맞춘 값

- 데모 환자 이지은: 체중 72.6kg(유지 범위 68–72 초과), 식욕 7일 평균 8.2, 수면 5시간, 2주간 +2.4kg — `src/data/mock.ts`의 `risk` 시나리오와 같음
- 내원 요청 메시지: "걱정할 단계는 아니에요. 지금 잡으면 충분히 돌아갈 수 있으니 이번 주에 한번 들러 주세요."
- 메모 태그는 환자 앱 홈의 원장님 메모 카드에 문장으로 보여주는 것을 전제로 해요 (태그 → 문장 매핑은 `index.html`의 `TAGS`)

## 데모 동작

- 환자 앱과 실제로 연결돼 있지 않아서, 내원 요청을 보내면 약 6초 뒤 환자가 첫 번째 제안 시간으로 예약한 것처럼 바뀌어요.
- 상태는 새로고침하면 처음으로 돌아가요.
